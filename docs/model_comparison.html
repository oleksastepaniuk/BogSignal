Lowering the bar for the rare classes

A model that picks the single most likely class per pixel chooses “other land” whenever it is unsure, so the maps come out too white. The maps on this page now use a lower bar: each rare class gets a fixed head start before the most likely class is chosen.

“Wetland found” is the share of reference wetland the map colours as wetland; “wetland correct” is the share of mapped wetland that the reference agrees with. Lowering the bar finds more and is right less often. The head starts were fitted for each fold on the other four folds' held-out predictions, so no patch helped set its own rule. Peat stays under-drawn because its labels come from a 1 km map the satellites cannot reproduce.

Shown at 80 m per pixel. The block was picked automatically: the biggest gap-free, roughly square rectangle, weighted towards more reference wetland. Neighbouring patches can come from different fold models, which is why some seams are visible.
